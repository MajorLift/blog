Connect a GitHub token

Publishing writes to two repositories, so it needs a token. Everything below stays in this browser's local storage and is sent only to api.github.com. No server of mine ever sees it.

Use a fine-grained personal access token with Contents: Read and write, scoped to only the two repositories, with a short expiry. Not a classic token. This page shares an origin with the rest of the site, so a long-lived broad token left here is a standing risk for no benefit.
